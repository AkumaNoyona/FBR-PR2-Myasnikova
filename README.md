# HealthLog Landing Page

Минималистичный лендинг для приложения "HealthLog" — дневника физического и ментального здоровья.

## Демо
[Посмотреть лендинг на GitHub Pages](https://akumanoyona.github.io/FBR-PR2-Myasnikova/)

## Технологии
- **HTML5** — семантическая разметка
- **CSS3** — кастомные стили
- **Bulma CSS Framework** — для компонентов и сетки
- **Font Awesome** — иконки

## Особенности
- Полностью адаптивный дизайн
- Минималистичный интерфейс
- Цветовая палитра:
  - Основной: `#7B68EE` (фиолетовый)
  - Фон: `#E6E6FA` (лавандовый)
  - Акцент: `#FFB6C1` (розовый)
- Мобильное меню-бургер
- Чистая, валидная вёрстка
